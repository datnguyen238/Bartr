## Implemented paths

## External and evaluation limitations

- Gemini/Bedrock/Atlas credentials and live vector index access have not been supplied or tested in this repository. Model availability and permissions must be checked in the team's accounts.
- MongoDB compare-and-swap persistence is implemented; actual Atlas restart/concurrent-write verification remains required. Domain concurrency tests use isolated in-memory storage, while JSON tests cover only a process-local lock and atomic file replacement.
- The `/sign-in` and `/register` screens implement the current username/password API. The planned route contract's email/password and 18+ self-attestation are not implemented; the screens do not satisfy that planned contract.
- Exact-text local mode does not meet the semantic-equivalence criteria; the configured semantic adapters need their labeled retrieval evaluation.
- The spec's 20-person pilot, 40-case recommendation quality set, 20 paraphrase cases, screen-reader audit, 1,000-listing/20-request load test and associated numerical targets have not been run and are not claimed achieved.
- Legacy MongoDB/JSON aggregate size and DynamoDB's compatibility snapshot/transaction limits bound this prototype's scale. Request contention or capacity failure is reported explicitly instead of falling back to unsaved data.
